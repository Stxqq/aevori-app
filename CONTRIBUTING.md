# Contributing

Use Node.js 22.13 or newer. Run `npm ci`, then `npm run dev`.
Before a pull request run `npm test` and `npm run build`; verify visible changes
at desktop and mobile sizes, with keyboard navigation and reduced motion.

Do not commit `.aevori/`, `.orbit/`, `.env`, API keys, team invitations,
private screenshots, user uploads or model weights. New artwork or imported
code needs a documented source and redistribution terms in ASSETS.md.

The adapted Efferd block retains its own terms. Do not extract it to create a
component library. Report suspected security issues privately through GitHub's
security reporting for this repository; do not publish credentials in an issue.
