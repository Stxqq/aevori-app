Your data. Your connection.

AEVORI · Updated September 30, 2026

On your device

AEVORI stores chats, notes, tasks, and uploaded images in browser storage. Agent conversations, memories, and team settings are stored on the Mac running AEVORI. AEVORI does not encrypt this storage itself. The app has no advertising trackers or built-in usage analytics and does not send this data to the project maintainers.

Local AI and your team

With local Ollama, your Mac processes requests. With a Mac pool or an invited team workspace, the shared host processes them. The local agent uses Ollama. Its memories are not automatically passed to a cloud API.

Optional cloud API

When you connect a cloud provider, chat messages, text and image attachments, and any Mac context you explicitly enable are sent to that provider. API keys remain in the local server's memory. A cloud connection is not local or offline. Browser dictation may also use your browser provider's speech service.

Meta Model API

AEVORI supports Muse Spark on the Standard tier with your own Model API key. Contributor models are excluded. Muse app logins and Muse Code subscriptions are not imported. Meta determines pricing, availability, acceptable use, and data processing.

Use this connection only with authorized access and under these terms. Do not share API keys with others. AEVORI is an independent client, with no partnership with or endorsement by Meta. AI-generated responses may be incorrect.
