# AEVORI design

AEVORI uses the supplied rounded wordmark, a restrained monochrome shell and
small expressive characters. The claim is “Aevori — Intelligence, locally.”

Theme colors use the shared application variables. Inputs keep the surrounding
surface color and use a clear contrasting focus outline. Message actions sit
outside reply bubbles. Components should remain readable at 390 px and support
keyboard interaction with visible focus.

Motion should explain change: expanding composer, measured dialog heights,
streaming state and subtle character movement. Respect both the operating
system's reduced-motion preference and AEVORI's Animations setting.

Do not introduce copied characters, product artwork, paid icon collections or
component code without documented redistribution rights. See ASSETS.md for the
current provenance and third-party license boundaries.

The rounded wordmark is restored in 0.2.1; its rights are unverified and excluded from MIT. Use neutral capability icons for providers, not their brand marks.

The 0.3 English showcase uses a charcoal canvas, the rounded wordmark, generous
left-aligned type and one large code panel. README badges expose actual project
status. The reply GIF records the real app with synthetic data, preserving response
timing and adding a reading pause at the end. Product copy is English throughout.
